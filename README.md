# Mythos-Humanity-Oficial
MYTHOS: Humanity é um projeto de RPG 2D ambientado no meu universo MYTHOS. Você assume o papel de alguém que já tem uma vida própria e acompanha sua passagem da juventude para a vida adulta. Crescer, escolher, se frustrar e viver as consequências transformam essa história.

## Ideia central

Estar presente em um lugar significa estar ausente em outro. Pessoas, relações e acontecimentos não existem apenas quando o protagonista está olhando. A vida Original apresenta uma trajetória própria; outras vidas poderão revelar caminhos e histórias que ficaram para trás.

Humanity quer reunir convivência, exploração, fantasia, perigo e amadurecimento em um mundo pequeno em extensão, mas profundo em possibilidades.

## Estado do projeto

O jogo está no início de uma nova construção. Este repositório ainda não representa um jogo completo nem uma versão disponível para lançamento.

O desenvolvimento será gradual. Cada etapa terá uma issue com um objetivo jogável e critérios de conclusão. Mudanças serão discutidas e revisadas em pull requests. O projeto não tem uma data de lançamento definida.

## Direção técnica

- Jogo 2D para a web, desenvolvido em JavaScript com Phaser.
- Regras narrativas e estado do mundo separados da apresentação visual.
- Suporte a conteúdo criado pela comunidade como objetivo futuro.
- Serviços e banco de dados serão introduzidos quando houver uma necessidade concreta para eles.

## Primeiro recorte

A primeira parte a construir é uma noite com amigos ao redor de uma fogueira: chegada do protagonista, movimento, convivência e uma interação que deixe uma consequência perceptível. O escopo exato será registrado em uma issue antes da implementação.
